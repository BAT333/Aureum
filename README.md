# Aureum  
Account management API developed in .NET 10 focusing on RESTful best practices.

🚀 Features
Full Account CRUD: Complete Create, Read, Update, and Delete operations.

Optimized Pagination: Data retrieval using PagedResultDTO.

Object Mapping: Clean data transformation with AutoMapper.

Auto Documentation: Fully integrated Swagger UI.

🛠️ Tech Stack
ASP.NET Core Web API

Entity Framework Core

AutoMapper

SQLite / SQL Server

🏁 Quick Start
Clone the repository.

Run dotnet ef database update to set up the database.

Run dotnet run to start the API.

Access /swagger to view and test endpoints.
